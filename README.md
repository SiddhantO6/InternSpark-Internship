# InternSpark-Internship
This repository is about the tasks that I've completed during the internship in InternSpark as Front End Develeoper
The Netflix clone code I provided is specifically designed as a "Hero Section" (the very first thing a user sees before scrolling). Even though it is a beginner friendly, single-file project, it actually uses some modern, industry-standard techniques.
Here is a breakdown of its features and exactly how the HTML, CSS, and JavaScript work together merged into a single file.
🌟 Key Features of the Clone:
Single-File Architecture: All the structure, styling, and logic are contained within one index.html file which makes it incredibly easy for beginners to test and share without worrying about file linking errors.
Immersive Background with Overlay: It uses a real Netflix background image, but applies a semi-transparent 'black tint' over it so the white text is easy to read.
Flexbox Layout: It uses CSS Flexbox (a modern layout tool) to perfectly align the navigation bar elements to the edges, and to center the main text in the middle of the screen.
Form Validation: The email input field uses the HTML required attribute. If a user tries to click "Get Started" without typing anything, the browser will automatically stop them and ask for an email.
Interactive JavaScript Popup: When a valid email is submitted, the page doesn't just reload. It intercepts the submission, reads what the user typed, and greets them with a personalized alert box.
